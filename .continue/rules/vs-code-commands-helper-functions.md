# VS Codeコマンドヘルパー関数

コマンドマップに新しいコマンドを追加するときは、コマンドロジックをインラインで定義するのではなく、常にコマンド用の個別のヘルパー関数を作成してください。`streamInlineEdit` のような既存のコマンドのパターンに従ってください - コマンドマップの下にヘルパー関数を定義し、コマンドのエントリ内からそれを呼び出します。
