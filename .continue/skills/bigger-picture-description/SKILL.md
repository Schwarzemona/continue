# 全体像の説明

ユーザーがコードの特定の部分がどのように動作するかを尋ねた場合：

## 1. コードが単独で何を行うかを説明する

コードベースの他の部分との相互作用を考慮せずに、そのコードの機能を説明してください。

## 2. コードベースの他の部分との相互作用を説明する

コードがコードベースの他の部分と相互作用する場合、そのコードが他の部分でどのようにインポートされ、使用されているかを説明してください。

## 3. 明確にするために親関数を含める

各ユースケースを説明する際は、明確にするために親関数を含めてください。
