# プログラミング原則

可能な限り関数型プログラミングのパラダイムを使用してください。必要に応じて既存のクラスを修正したりシングルトンを作成したりすることは許容されますが、それ以外の場合は関数を使用してください。

# TypeScript enumの使用

TypeScript コードでは、可能な限り単純な文字列の Union 型ではなく enum を使用してください

# any型の禁止

可能な限り `any` 型の使用を避けてください。`unknown` を使用するか、正しい型を見つけてください。`any` の使用が許容される唯一の場所は、テスト用のモックのために型キャストする場合のみですが、それでも可能な限り避け、適切なモックを提供することが推奨されます。
